# Job Market Trends and Insights using Power BI

## Project Overview
This project focuses on analyzing global job market trends using Power BI. The dashboard provides insights into job postings, salary distributions, industries, employment types, experience levels, and location-based trends.

## Tools and Technologies
- Power BI
- Power Query
- DAX
- Excel
- Data Modeling (Star Schema)

## Project Features
- Three-page interactive dashboard.
- Job posting and company analysis.
- Salary and industry analysis.
- Experience-level and employment-type analysis.
- Job location and remote work analysis.
- Skills demand analysis.

## Data Preparation
- Checked data types.
- Inspected missing values and duplicates.
- Performed data cleaning and transformation using Power Query.
- Created dimension tables and established relationships using a star schema.

## Key Insights
The dashboard helps explore job market patterns, salary distributions, in-demand skills, and employment trends across different industries and locations.
